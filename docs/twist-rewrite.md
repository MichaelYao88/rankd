# Facts rewrite

Player-facing label is now **Facts:**. Each line below is the results-screen fact for a Rank it puzzle.
Pattern `contrast-why` means the line names a surprising pair (or upset) and a checked reason: geography, history, policy, culture, or how the stat is measured.
Pattern `verified-fact` means there was no solid causal explanation, so the line is a tightened fact from the puzzle's own source, with the caveat kept.
